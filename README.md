# Universal Python File Organizer & Automation Web App

[![Python](https://img.shields.io/badge/Python-3.8%2B-blue.svg)](https://www.python.org/)
[![FastAPI](https://img.shields.io/badge/FastAPI-0.110.0-emerald.svg)](https://fastapi.tiangolo.com/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

An open-source, full-stack **Python automation tool** designed to solve digital clutter globally. It instantly sorts hundreds of file types (documents, images, archives, code, spreadsheets) into structured professional categories locally on your desktop or via a modern web interface.

## 🚀 Features
- **Local Machine Scanning:** Point Python directly to your messy `Downloads` folder to clean it instantly.
- **Web Interface:** Includes a responsive HTML/Tailwind CSS dashboard powered by **FastAPI**.
- **Universal Extension Mapping:** Handles over 50+ file formats natively across 9 clean buckets (Images, Documents, Spreadsheets, Code, Archives, Audio, Video, Presentations, Executables).
